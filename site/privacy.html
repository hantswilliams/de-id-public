Privacy

Beta site · 2026-10-20

This website

  • It sets no cookies and runs no scripts.
  • It loads nothing from third parties: no fonts, analytics, tags or embedded forms. Open the network tab and look.
  • It collects nothing. There is no form on it. The only ways to reach us are a link to the issue tracker on GitHub and an email link, both of which leave this site and are covered by GitHub's and your email provider's own policies.
  • Hosting. The site is served by Cloudflare Pages, which keeps ordinary server logs (IP address, time, page requested) under its own policy. We don't add to them, and we don't run analytics on them.
  • Downloads are served by GitHub Releases, under GitHub's policy.

The app

  • It makes no network connections. No account, no telemetry, no update check, no crash reports, no cloud model. Every release is tested with the network blocked before it ships; see the release notes.
  • Your documents, the clean copies and the cross-reference stay on your computer, in your own folders and in ~/Library/Application Support/io.github.hantswilliams.deid/. We never receive any of them.
  • Feedback you send us by email or on GitHub is read by us and kept as long as it's useful for the beta. Please don't paste real identifiers into it; de-identify first.
