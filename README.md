# de-id-public

Public releases of the De-ID tool. Website: https://hantswilliams.github.io/de-id-public/

## macOS: 0.7.8 (beta, recommended)

- [Release notes](https://github.com/hantswilliams/de-id-public/releases/tag/desktop-v0.7.8)
- macOS 14 or later, signed and notarized. Apple menu → About This Mac shows which chip you have.
  - Apple silicon (M1 or newer): [De-ID_0.7.8_aarch64.dmg](https://github.com/hantswilliams/de-id-public/releases/download/desktop-v0.7.8/De-ID_0.7.8_aarch64.dmg)
  - Intel: [De-ID_0.7.8_x64.dmg](https://github.com/hantswilliams/de-id-public/releases/download/desktop-v0.7.8/De-ID_0.7.8_x64.dmg)

## Windows: 0.4.3 (beta, earlier version)

- [Release notes](https://github.com/hantswilliams/de-id-public/releases/tag/desktop-v0.4.3)
- One installer for every Windows PC: Windows 10 or 11 on Intel or AMD, and Windows 11 on ARM
  (under Windows' built-in emulation):
  [De-ID_0.4.3_x64-setup.exe](https://github.com/hantswilliams/de-id-public/releases/download/desktop-v0.4.3/De-ID_0.4.3_x64-setup.exe).
  It doesn't have what's new since 0.5. The installer isn't signed yet: when SmartScreen shows
  "Windows protected your PC", choose **More info**, then **Run anyway**.

## Linux: coming soon

`.deb` (Ubuntu 22.04+, Debian 12+) and `.rpm` (Fedora 36+; RHEL, Rocky and Alma 10) packages,
for Intel/AMD and ARM, are being tested.
